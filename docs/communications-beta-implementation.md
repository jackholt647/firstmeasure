# Communications beta implementation journal

The user authorized a complete unified communications/calls implementation, real Telnyx backend, and functional/visual polish. This is an implementation record, not release approval. The accepted specification is `communications-call-center-spec.md`; deployment and rollback instructions are in `communications-beta-deployment.md`.

## Implemented

- Canonical calls, legs, events, durable jobs/webhooks, claims, idempotent operations, scripts, artifacts, resources, workflow/read markers, and provider usage in the existing communications SQLite database.
- Authenticated, CSRF-protected APIs for calls/lists/follow-ups/scripts, contexts, voice setup and routing, endpoints/presence, call commands, diagnostics, reconciliation, health, private media, deletion, and background-work recovery.
- Real Telnyx REST integration and raw-byte Ed25519 webhook verification. Staff-first outbound, inbound queues, branch/team routing, conference hold/resume, warm/cold consultation transfer, voicemail, consent-controlled recording/transcription, protected media ingestion and playback, retention/tombstones.
- Optional voice; tenant-owned SMS numbers retain SMS and their previous voice route. Provider settings sync before local changes, deterministic provisioning reconciliation, bounded calling limits, expiring credentials, endpoint leases, session/heartbeat recovery, and a SIP-only device diagnostic (no public test-number call).
- Unified Communications Inbox, Call lists, Follow-ups, History, Call center, Scripts, and Phone setup. Calls remains a shortcut. Persistent shared phone workspace; versioned scripts, questions, autosaved notes, explicit source-work completion, organization timezone/cadence suggestions, appointment selection, project/contact links.
- Calls in global/project activity and inbox. Project Communications Calls tab and contextual settings drawer. Contact Call action and shared Work open-customer-call actions. Native email/SMS/web-chat behavior retained, with assignment/resolve/snooze/read controls and Snoozed view. Inbox filters persist through Portal.navigation.
- Legacy list disposition endpoints adapt into canonical calls with deterministic effects and compatible responses. Call lists retain roles, assignees and advanced rules. Additive historical migration defaults to dry run and creates no new phone calls or work.
- Provider costs are recorded as evidence by leg, with unknown values preserved. This is not a tenant billing/markup implementation.
- Emergency short codes are blocked. The beta does not provision E911, and service-location entry does not activate it. The setup UI requires an alternate emergency phone acknowledgment.
