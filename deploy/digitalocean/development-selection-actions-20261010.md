# Development 3D selection action menu

October 10, 2026. Source: `e30e45c9b436624fab2e90d43e8887b2b92bfe35`, integrated on the canonical GitHub branch through `f4f1ffe5`.

A stationary right-click in the 3D view opens available selection commands next to the cursor. Each row shows its shortcut followed by the action name. Menu clicks and shortcuts dispatch through the existing editor keyboard handlers. Opening, Escape, and outside-click dismissal preserve the selection. Right-button drags continue camera navigation. The menu supports arrow-key navigation, Enter, viewport clamping and scrolling without zooming the scene.

The action list distinguishes roof, base, wall and drawing-plane selection. It resolves overloaded keys such as Connect/Chamfer, Rotate/Fillet, Flip/Trim, and base pitch versus geometry resize. Active editing tools retain their existing interaction rather than showing a stale selection menu. The 3D routing is retained even when moving onto the floating menu leaves the canvas.
