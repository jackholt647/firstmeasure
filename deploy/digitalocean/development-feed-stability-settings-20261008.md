## Tile text overflow follow-up

Source commit `5858f0ccf996d507cede333c865f8a6b09543bc6` constrains the content of small, large, and mosaic activity tiles to each card's width. The previous column flex alignment let a long note create a 2,783-pixel content box inside a 92-pixel tile. That box painted text over adjacent cards and created horizontal scrolling. The corrected alignment makes the note measurement and text wrap within the tile. The Feed asset cache version advanced to `20261008-feed-tile-width-v4`.
