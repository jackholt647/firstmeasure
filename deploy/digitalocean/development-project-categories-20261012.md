# Project resource type removal and column controls — October 12, 2026

Resource types could be created and edited but not removed. A custom type can now be removed from its column heading. `archiveResourceType` in `materials/resource-types.ts` requires `manage_projects`, refuses the built-in Materials, Labor and Equipment types, and refuses a type while any unarchived list in any project still uses it (the error gives the list and project counts). It retires the record with `archived_at` rather than deleting it, so the id cannot be reused, and honours `expected_revision`. Archived types no longer appear in the catalog and fail `requireResourceType`. The writer is exposed as `DELETE /organizations/:orgId/resource-types/:typeId`, as the published action `materials.resource-type.archive` (version 1, granted through the `manage_projects` bundle beside create and update) and as `MaterialsAPI.resourceTypes.archive`. The Project tab refuses locally while the type still has lists in the open project and confirms before removing.

The same release reworks the Project action header: restore tabs for minimized columns sit on the left; Category, Regenerate and the Measured/Order switch (now a ruler or boxes icon, not a refresh icon) sit on the right with tooltips. Minimizing a column animates it into its tab and restoring animates it back. Dividers between columns are draggable and keyboard adjustable, trade width between two neighbours, are remembered per browser, and reset on double-click.

## Divider fix

Release `2cd4c8d27bf0333aacda35553e11526ed95bb114` fixed the column dividers. The first drag collapsed both neighbouring columns and the next redraw reset them: the divider read each column's weight through the file's `number()` helper, which returns 0 rather than its fallback for a missing value, so two unset columns had a combined weight of zero and zeros were saved. Unset or zero weights now default to 1, which also repairs zeros already saved in a browser. The earlier headless check stubbed that helper and missed it; `tests/project-scope-work-browser.test.mjs` now covers the divider with the real helper (14 passing). Staged, activated and verified on compatibility, web and pool over audited `9810ddcb69c5075e2d078f1b0edebc40b8dbc590` baselines.
