FirstMeasure API

Docs + Tester

Single report model. Use one report endpoint and vary `branding` plus `prepared_for` to get internal or customer-facing output.

Overview

Current Shape

Internal reportSend default branding and omit `prepared_for`.
Customer reportSend company branding and include `prepared_for`.
Stored default`GET /projects/:id/pdf` returns the saved default `Report.pdf`.
Gutter optionProjects now use `include_gutter_measurements` as a simple boolean.
