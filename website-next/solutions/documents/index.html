Questions

Can I use my existing contract?
Placeholder answer about rebuilding an existing contract as a template.
What if I need to change one document but not the template?
Use Edit manually. Your change applies to that document only, and the rest stays connected to the project data.
Can a total be typed over?
No. Totals and other calculated values are always worked out from the lines, so the document never disagrees with itself.
